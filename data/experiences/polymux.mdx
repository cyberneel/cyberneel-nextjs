A self-hosted dashboard for running Claude Code and Codex sessions from the browser.

=ReAdMoRe=

## Highlights
- Runs each session in tmux behind an in-browser terminal, so sessions outlive closed tabs and restarts, and come back after a reboot.
- Launches, resumes and forks sessions in any project folder, with live previews in a grid, list or grouped view.
- Exposes an MCP endpoint so Claude and other agents can search past work and drive sessions remotely.
